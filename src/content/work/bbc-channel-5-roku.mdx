## The role

UK broadcasters expect their Roku apps to be reliable, quick and consistent with their brand on every device. As **Lead Roku Developer** I was responsible for the BBC and Channel 5 Roku work: architecture, development, code quality and releases.

## What I did

- **Led development** of the Roku applications, from technical design to delivery.
- **Wrote the team's Roku documentation on code conventions and best coding practices.** It became the standard onboarding resource for every new Roku developer joining the team.
- **Set design and coding standards** so the codebase stayed consistent as the team grew.
- **Mentored junior developers** in the Roku team.

## The BBC app

The new BBC Roku app was built on my [custom MVVM framework](/work/roku-mvvm-framework/). Its interface followed the BBC's new visual language, which was being developed in parallel for the BBC website, so the TV app would look and feel part of the same product family.

We built the app's full library of UI components in this modern style, together with the architecture to support them. When the BBC discontinued the project, before launch, every component was complete and ready to be connected to live data as soon as the BBC's APIs were finalised.

## The outcome

- **Channel 5:** app delivered to production.
- **BBC:** a complete component library and app architecture, ready for API integration when the BBC cancelled the project. The app was not released.
- **The team:** shared standards and documentation that made onboarding new Roku developers much faster.
